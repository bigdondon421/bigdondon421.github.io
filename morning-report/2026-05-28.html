昨日複盤銜接

  • 昨天複盤的核心定義是：科技核心權值掌盤，但不是整條科技鏈全面共好，而是主鏈中樞更強、周邊次族群被重新排序。
  • 昨天市場最強的是台積電、聯發科、台達電、聯電、日月光，以及 IC設計、FLASH、晶圓代工等中樞段。
  • 相對地，光通訊、封測、硬板、DRAM、IC基板、矽智財與散熱等周邊次族群仍在被明顯調節。
  • 所以今天盤前最重要的延續問題，不是科技會不會整包翻空，而是：主鏈中樞在昨晚降溫後，市場會把資金轉向哪些能接棒的線。

總經重點

  • 昨晚美股四大指數整體偏穩，道瓊 +0.36%、S&P500 +0.02%、那斯達克 +0.07%，但 費城半導體 -1.36%，顯示科技主導權正在降溫。
  • VIX 16.29、-4.18%，說明這不是市場恐慌，而是風險偏好沒有壞，只是主線從集中科技轉向更分散的輪動。
  • 2330 ADR +1.32%，代表即便費半回落，台積電 ADR 並沒有被明顯拖累，這對今天台股是重要緩衝。
  • WTI 89.59、DXY 99.219、USDTWD 31.438，整體流動性與通膨壓力環境仍算友善，不構成今天盤前最大的壓力來源。

  • 昨晚最重要的變化，不是全面升溫，而是：強勢段落開始擴散，但半導體本身不再像前晚那樣獨占全部注意力。

  • 所以今天最有價值的動作不是全面追，而是：沿著仍有承接的主線與延伸線，做更細的篩選。

今天對 ARK 的意義

  • 第一主線仍然是 2330 / 2303 / 核心半導體中樞，但今天不能再用「全面半導體強攻」語言看待市場，因為昨晚費半與設備段已開始降溫。
  • 第二主線是 00910 / SATL / FIREFLY / 通信設備 / 航太延伸，這條線昨晚仍在承接區，是今天更值得留意的延伸優勢。
  • 風控 66.3% 說明市場沒有把甜度吃光，但也不再是前幾天高甜期。操作上應從「甜區大量撿」轉向「主線精準選」。
  • 今天核心結論：盤前不是全面風險擴張，也不是市場轉空，而是主線從單一半導體強攻轉成多路輪動。對 ARK 來說，重點是確認哪些線仍有資金承接，尤其是通信 / 航太延伸能否與台股底盤形成共振。
