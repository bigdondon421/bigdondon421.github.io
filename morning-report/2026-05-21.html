看主鏈修復能否傳導
今天要看半導體與電子主鏈能否把美股修復正式接到台股現貨，而不是只停在夜盤強。

昨日複盤銜接

  • 昨天複盤結論是：5/20 屬於主鏈深壓後的弱反彈修補日，主鏈金流還沒回來，但風控已升到 75%，高甜度持續擴張。
  • 也就是說，昨天市場在價格上止血，但還沒有給出「主鏈正式修復」的證據。
  • 昨晚美股最重要的新變化，就是這個缺口被補上了，因為不只費半大漲，連產業金流也正式回到半導體與設備鏈。
  • 所以今天盤前最關鍵的問題，不再只是主鏈能不能止血，而是：主鏈修復能不能從美股價格與金流，正式傳導到台股現貨。

總經重點

  • 昨晚總經主因最清楚的是：油價回落到 101.93，讓前幾天壓著市場的通膨與估值焦慮先暫時鬆一口氣。
  • 同時 VIX 維持 17.81 低檔，代表這不是恐慌中硬拉的反彈，而是風險偏好重新打開後的正常修復。
  • 指數面上，道瓊 +1.31%、那指 +1.54%、S&P500 +1.08%、費半更大漲 +4.49%，這代表美股不只是止血，而是有一波更明確的科技主線修復。
  • 總經上最準的定義是：高油價壓力稍緩，市場把風險偏好重新打開，從前幾天的防守與低波動避風，轉向科技主鏈與高β資產的修復。

美股價值區 / 升溫區交叉比對

  • 昨晚很關鍵的一點是：很多強彈標的仍留在價值區，例如 AVGO、ASML、AMAT、MU、LRCX、AMD、SATL、GEV、BE，代表主鏈修復雖強，但系統仍未把它們判成過熱。
  • 這對方舟來說是好事，因為代表「有漲 + 有金流 + 仍在價值框架」，比單純過熱追價健康得多。
  • 升溫區則保留：CSCO、BKSY、SATL，說明通信設備與衛星 / 航太延伸沒有被主鏈修復排擠掉，反而和主鏈一起保留強勢。
  • 這意味今天不是主鏈和延伸主題互搶，而是：半導體修復與衛星 / 通訊延伸可以同時存在。

今天對 ARK 的意義

  • 你現在的策略仍然是：在 75.6% 的高甜度風控下，讓分散式價值區鋪倉法繼續運作，不用因為一晚強彈就從系統邏輯切去追高模式。
  • 但今天比昨天更值得看的是：2330、2303、00830、00911、00941 這條半導體主鏈，有沒有正式接到美股的修復，而不是只停在夜盤好看。
  • 同時，00910 / SATL / 華通 / 通訊延伸 也要看是否在主鏈修復的背景下，繼續保有相對強度，因為昨晚航太國防與通信設備沒有掉隊。
  • 今天核心結論：盤前不是單純反彈，而是油價回落後帶動的主鏈修復盤。對 ARK 來說，今天最重要的是觀察主鏈修復能不能正式傳導到台股現貨，同時看衛星 / 通訊延伸是否能維持共振。
